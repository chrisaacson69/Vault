# 6502
> Files about the 6502 CPU family (6502, 6507, 2A03) and software written for it.

- [Game Annotation Series](../projects/game-annotation/README.md) — documenting classic game source at the system level; meta-stress-test for LLM interpretation of low-level code
- [TIA Reference](../research/atari-2600/tia-reference.md) — Television Interface Adaptor specs; 6507's role in beam-racing
- [PPU Reference](../research/nes/ppu-reference.md) — Ricoh 2C02; registers, NMI timing, OAM, scrolling, VBlank window
- [APU Reference](../research/nes/apu-reference.md) — 5-channel audio with autonomous envelope/sweep/length-counter
- [Mappers Reference](../research/nes/mappers-reference.md) — NROM, MMC1, MMC3, etc.; cartridge logic that scales the platform
- [NES Research](../research/nes/README.md) — platform overview; 2A03 vs 6507 comparison; storytelling-vs-logic axis
- [Battlezone (1980) — 3D Without a Multiply Instruction](../research/gaming/battlezone-mathbox.md) — the 6502's missing MUL/DIV as a design constraint: every real multiply offloaded to a 2901 coprocessor; shifts, `CMP #$80`/`ROR` arithmetic-shift-right, and table lookup are all the CPU keeps
- [Arithmetic Scarcity and the 3D Problem](../research/gaming/arithmetic-scarcity-3d.md) — the 6502's missing MUL/DIV placed on the wider curve: PDP-8 EAE → PDP-11 EIS → 8087 → integrated FPU; fast math as a purchasing decision for three decades
- [Stellar 7 (1983) — The Same Game Without the Coprocessor](../research/gaming/stellar7-software-3d.md) — what 6502 software arithmetic actually costs: a 695-byte `Divide16` and a fully-unrolled signed 16×8 multiply, the routines Battlezone contains none of
- [Arithmetic as a Purchase — Sixty Years of Paying for Multiply](../research/arithmetic-as-a-purchase.md) — the 8-bit era as a *regression*: the 6502 could do less arithmetic than a 1959 mainframe or a 1966 spacecraft, because every cheaper substrate loses the capability and has to re-earn it
